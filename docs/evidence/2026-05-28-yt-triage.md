## Сигнатура root cause

В events задачи 11661 (типично для всех 9):

```
yt_0_foreground_guard  ui_dump usable=True bytes=24675   ← живой dump (YT впереди)
yt_1_feed              ui_dump usable=True bytes=24675   ← живой
yt_1_dismiss           ui_dump usable=False bytes=4936   ← stale (после dismiss-тапа)
yt_2_profile_screen    ui_dump usable=False bytes=4936   ← stale
yt_3_retap_probe1      ui_dump usable=False bytes=4936   ← stale
yt_3_retap_probe2      ui_dump usable=False bytes=4936   ← stale
yt_3_alt_avatar_probe  ui_dump usable=False bytes=4936   ← stale
yt_3_open_accounts_postmortem  ui_dump usable=False bytes=4936
→ ERROR  yt_accounts_btn_missing_postmortem
→ yt_settings_activity_fallback_start (T9)
→ ERROR  yt_picker_failed_to_open: кнопка "Аккаунты" не найдена после всех recovery-путей
```

* `bytes=4936` — известная сигнатура stale-uiautomator (тот же байтсайз, что в evidence WP#131 для TT).
* Fg-guard срабатывает на ХОРОШИЙ dump → код считает «YT впереди».
* Сразу после fg-guard — uiautomator залипает (Compose hierarchy / FLAG_SECURE / Surface-only window?), и все следующие dumps возвращают «обрезок» без UI-tree.
* `_yt_try_accounts_btn_with_retries` (`account_switcher.py:4405`) видит пустые `elements`, ни один trigger не матчится → 2 ретрая, alt-avatar, postmortem.
* T9-fallback `_yt_open_via_settings_activity` (`account_switcher.py:4485`) запускает intent `Shell_SettingsActivity` — но дальше тоже читает UI-dump'ы → ещё одна серия stale → `yt_picker_failed_to_open`.

## Сходство с WP#131 / WP#164 / WP#105

* TikTok: `_tt_probe_looks_stale` (`account_switcher.py:2781`) + `_tt_dumpsys_confirms_foreground` (`account_switcher.py:2801`); kill-switch `TT_STALE_UI_OWN_PROFILE_GUARD` (default ON, `account_switcher.py:330–335`); honest emit `tt_own_profile_stale_ui`; в петле tap-profile вместо retap'ов (`account_switcher.py:3124–3149`).

## Что предлагается WP #180

1. `_yt_probe_looks_stale(xml, target_pkg)` — пустой XML, нет YT-пакета или `is_dump_usable=False`.
2. `_yt_dumpsys_confirms_foreground(...)` — dumpsys 2–3 раза подряд, без uiautomator.
3. Honest emit `yt_own_profile_stale_ui` вместо `yt_accounts_btn_missing_postmortem` (variant=opaque_hierarchy/launcher_empty).
4. Recovery: `am force-stop` + relaunch + re-tap profile; на повторный stale — честный fail без жжения retap'ов.
5. Kill-switch `YT_STALE_UI_OWN_PROFILE_GUARD` (default ON).
6. TDD: stale-dump кейсы + flow-тест.
