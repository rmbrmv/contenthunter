## Summary

WP #115 delivers a **client-level manual-publish flag** on `validator_projects`:

- **Admin UI** (`/clients` table): toggle per-client publish mode (auto ↔ manual) via PATCH endpoint; frontend column reflects state
- **Retroactive cascade on enable**: all pending `publish_queue` rows (and pending `unic_tasks`) for the client are cancelled with `skip_reason='client_manual_enabled'`, preventing double-publish
- **Retroactive cascade on disable**: only `validator_manual_publish_queue` rows for slots that are manual *only* because of the client flag are cancelled; per-slot-manual rows are preserved
- **autowarm filter** (`effectiveManualSql`): `slot.manual_publish OR project.manual_publish` — wired into auto-guard (server.js), manual-queue assignment, and slot-matcher cron; single kill-switch `CLIENT_MANUAL_PUBLISH_ENABLED=0` reverts all 3 sites atomically
- **RBAC**: admin-only endpoint; manager → 403
- **Idempotent**: no-op if flag already at target value
